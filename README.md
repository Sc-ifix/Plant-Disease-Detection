# Plant-Disease-Detection


<img width="1280" height="640" alt="banner" src="https://github.com/user-attachments/assets/32e1df83-54b7-4302-a9ad-d5b73a204567" />


Upload a photo of a plant leaf and get a diagnosis of what disease it has, if any. The app runs an image classification model behind a simple web interface, so you don’t need any ML knowledge to use it.  Built to make early plant disease detection easier for anyone with a phone camera.  

Dataset: PlantVillage

https://helpful-sjerlhe.peachworlds.com/

Note: Training data had images in a certain condition and lighting, online images outside these conditions may not work properly
